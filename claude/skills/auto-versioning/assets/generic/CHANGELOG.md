# Changelog

All notable changes to this project are documented here.

Sections below the marker are generated automatically by
`.github/workflows/auto-version.yml` from [Conventional Commit](https://www.conventionalcommits.org/)
messages on each push to `main`:

- `type!:` subject or a `BREAKING CHANGE:` footer → **major** bump
- `feat:` → **minor** bump
- `fix:` → **patch** bump
- anything else → no release
- add `[skip version]` to a commit message to skip a release
