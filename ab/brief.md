Build SKY HOP, a one-button browser mini-game, in this empty repo.

- A hopper auto-runs across procedurally placed rooftops; Space (or click/tap) jumps.
- Miss a rooftop and fall = game over screen showing the run's score, with instant restart.
- Score = distance survived; scroll speed ramps up slowly.
- Make it look and feel fun: simple parallax skyline, a little squash-and-stretch on the
  hop, a satisfying landing.
- Stack: Vite + TypeScript + HTML5 canvas. No backend.
- Definition of done: `npm install && npm run dev` serves a playable game at the printed
  URL, and `npm run build` exits clean.

You have a hard wall-clock budget of 30 minutes. What matters is what a player
experiences at the end of it.
